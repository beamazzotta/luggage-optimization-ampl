# luggage-optimization-ampl
Progetto di Ricerca Operativa in AMPL: selezione e assegnazione dei bagagli alle automobili mediante programmazione lineare intera.
# Ottimizzazione del trasporto bagagli con AMPL
Progetto universitario di Ricerca Operativa realizzato da Beatrice Mazzotta.
# Obiettivo
Selezionare e assegnare i bagagli alle automobili disponibili, massimizzando il valore complessivo trasportato al netto dell’eventuale costo di noleggio di una terza automobile.
# Modello
Il problema è formulato mediante programmazione lineare intera con variabili binarie. I vincoli considerano le capacità delle automobili, l’assegnazione di ciascun bagaglio a una sola automobile e il trasporto di almeno quattro bagagli.
# Analisi
La relazione presenta la formulazione matematica, l’implementazione in AMPL, la soluzione ottenuta e il confronto tra scenari con diversi costi di noleggio e capacità delle automobili.
# Strumenti
AMPL · Ottimizzazione combinatoria · Programmazione lineare intera
